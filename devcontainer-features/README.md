# Dev Container Features

This directory holds reusable Development Container Features that ship alongside `course.md`.

## Layout

* `src/` contains the published Feature definitions.
* `test/` contains mirrored Feature tests executed by `devcontainer features test`.

## Local Testing

From this directory, run:

```bash
devcontainer features test -f course-md --base-image mcr.microsoft.com/devcontainers/base:debian .
```

To run scenario coverage only:

```bash
devcontainer features test -f course-md --skip-autogenerated .
```

## Publishing

The GitHub Actions workflow in `.github/workflows/publish-devcontainer-feature.yml` publishes Features from `src/` to GHCR under the repository namespace.

Feature releases are semver versioned independently from the `course.md` package ref installed by a Feature option.
If a Feature's installation behavior changes, bump the Feature version before publishing so consumers do not stay pinned to a stale artifact.
